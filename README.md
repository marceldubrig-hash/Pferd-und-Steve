# Pferd und Steve

Absurder Mobile-Pferde-/Tamagotchi-Simulator.

## Aktueller Stand

- Comic-Farm: Tag/Nacht vorhanden
- realistisches Pferd als bewusster Stilbruch
- eine Seitenansicht; Richtungswechsel später per horizontalem Spiegeln
- stehende Master-Pose vorhanden
- Cutout-Rig vorbereitet: Körper, Kopf, Unterkiefer, Schweif und Beinsegmente
- Mundprinzip: nur der Unterkiefer klappt wie bei einer billigen ausgeschnittenen Puppe
- Sprache/Vertonung zunächst Deutsch

## Asset-Regel

Bestehende bestätigte Assets nicht ungefragt neu generieren oder stilistisch verändern.
Neue Versionen immer versioniert ablegen.

Siehe `docs/MASTER_SPEC.md` für den verbindlichen Projektstand.
